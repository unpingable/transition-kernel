# Canonical receipt bundle — the summit specimen (`stage3b2-first-effect`)

Four real end-to-end durable bundles, generated by `generate.py` over the live `la_cli` +
`transition-cli`. Each directory holds the durable `durable.jsonl`, the orchestrator `result.json`, the
`reconstruct.json` (the replay-legible terminal state), and `reconstruct_composed.json` (Stage 3c: the
terminal state **with the governing composed admission snapshot attached and its coherence checked**).
This is the proof that the claim is not laboratory-born prose.

| Bundle | What it shows | Terminal |
|---|---|---|
| `success/` | consume → EffectAttemptReceipt → `create_new(marker)` → outcome; the marker exists and verifies | `consumed_effect_succeeded` |
| `refusal/` | eligibility recombination → binding refuses BEFORE consume; **fail-closed is not fail-silent** (a durable `infra_refusal`, no consume) | `not_consumed_refused` |
| `crash-reconcile/` | process death after the effect, before the success receipt → reconstruction **recovers success from the marker** without repeating the effect | `consumed_effect_succeeded` (reconciled) |
| `replay-refusal/` | the same operation replayed → LA `AlreadyConsumed`; the effect runs once | one spent event, replay refused |

Ordering invariant (see `success/durable.jsonl`): the `composed_snapshot` is pinned **before** the burn,
the `consume_receipt` (which references the snapshot hash) is durable **before** any effect attempt, and
`effect_outcome` comes last. `EffectSucceeded` is only emitted after post-effect verification (path exists
+ content hash matches) — a returned write success is not testimony.

Stage 3c (composed snapshot coherence): the `composed_snapshot` record pins the exact admission state that
governed the effect — the verified opaque `eligibility_reference`, the execution-clock revalidation facts
(`revalidated_at` / `revalidation_valid_until` / `revalidation_live`), the candidate basis hash, and the
capability nonce — reduced to one canonical `snapshot_hash` (RFC 8785 JCS + SHA-256) that the
`consume_receipt` references. A verifier (`reconstruct_composed`) recomputes the hash and refuses any chain
where the snapshot is missing, tampered, lossy (claims liveness with no clock), or referenced by a
different hash. `refusal/` has no snapshot: it refuses at the binding, before the snapshot is emitted.

Regenerate with `python3 generate.py` (requires both binaries built). The `sandbox/` marker files are
gitignored — the durable receipts are the specimen, not the environment-specific marker paths.
