# Canonical receipt bundle — the summit specimen (`stage3b2-first-effect`)

Four real end-to-end durable bundles, generated by `generate.py` over the live `la_cli` +
`transition-cli`. Each directory holds the durable `durable.jsonl`, the orchestrator `result.json`, and
the `reconstruct.json` (the replay-legible terminal state). This is the proof that the claim is not
laboratory-born prose.

| Bundle | What it shows | Terminal |
|---|---|---|
| `success/` | consume → EffectAttemptReceipt → `create_new(marker)` → outcome; the marker exists and verifies | `consumed_effect_succeeded` |
| `refusal/` | eligibility recombination → binding refuses BEFORE consume; **fail-closed is not fail-silent** (a durable `infra_refusal`, no consume) | `not_consumed_refused` |
| `crash-reconcile/` | process death after the effect, before the success receipt → reconstruction **recovers success from the marker** without repeating the effect | `consumed_effect_succeeded` (reconciled) |
| `replay-refusal/` | the same operation replayed → LA `AlreadyConsumed`; the effect runs once | one spent event, replay refused |

Ordering invariant (see `success/durable.jsonl`): `consume_receipt` is durable **before** any effect
attempt; `effect_outcome` comes last. `EffectSucceeded` is only emitted after post-effect verification
(path exists + content hash matches) — a returned write success is not testimony.

Regenerate with `python3 generate.py` (requires both binaries built). The `sandbox/` marker files are
gitignored — the durable receipts are the specimen, not the environment-specific marker paths.
